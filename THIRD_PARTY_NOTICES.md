These are public entry points of the official Solana Kit SDK. The lockfile
records the exact dependency graph. The build collects full license and notice
texts in `dist/licenses/`; its `index.json` records package versions, source
locations, hashes and unresolved coverage. Exact upstream sources are recorded
when an installed package omits its license file. Any discrepancy between
package metadata and upstream license text remains explicit in that index.
The current bundle has 26 reachable packages with 26 full license texts and no
unresolved metadata conflicts. This does not establish a deployment or live
network verification. Keep the entire `dist/licenses/` directory alongside any
distributed vendor bundle, including any legal-comment sidecar generated by a
future build.
